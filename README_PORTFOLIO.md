# Noyrax - Documentation that never drifts

**Built in 2 months. No CS degree. Open source.**

---

## The Problem

**80% of documentation is outdated.** Developers change code, but not docs. Code reviews don't catch it. CI doesn't check it.

**Impact:** Onboarding takes weeks. Bugs from outdated info. Wasted time searching.

## The Solution

**Noyrax** – An AI-native documentation system that automatically generates, validates, and maintains documentation.

**Built in 2 months** with TypeScript, VS Code Extension API, and MCP-Server.

## Key Metrics

- **71 modules** automatically documented
- **99 MCP-Server resources** for AI-agent navigation
- **27 Architecture Decision Records**
- **5-dimensional navigation space** for AI agents

## Use Cases

**1. Automatic Documentation Generation**
Automatically generates Markdown docs from code. Documentation stays in sync automatically.

**2. Drift Detection in CI/CD**
Validates documentation against code. Merge requests blocked if docs are outdated.

**3. AI-Agent Integration (Cursor, Copilot)**
Provides structured access via MCP-Server. AI agents navigate intelligently.

**4. Multi-Dimensional Navigation Space**
5-dimensional coordinate system:
- Module Space (X): API documentation per file
- Symbol Space (Y): Symbols with dependencies
- Relationship Space (Z): Module dependencies
- Knowledge Space (W): Architecture Decision Records
- Time Space (T): Changes over time

## Technical Highlights

- **TypeScript** – Type-safe, maintainable code
- **VS Code Extension** – Native IDE integration
- **MCP-Server** – Structured AI-Agent communication
- **Reality-Driven Development** – Verification loops prevent hallucinations

## Impact

**For Developers:** Documentation stays in sync automatically. Less time writing docs. Faster onboarding.

**For Teams:** Reduced technical debt. Better code reviews. Automated maintenance.

**For AI Agents:** Structured codebase access. Multi-dimensional navigation. Impact analysis.
